# Office Plants

Installable web app (PWA) for keeping track of office plants: overview, watering
schedule, water round, photo per plant. Runs on iPhone and Android via
"Add to Home Screen".

## Stack

- Vite + React + TypeScript + Tailwind, `vite-plugin-pwa`
- Supabase project `office-plants` (`adagtmentbsommzgbona`, eu-central-1):
  auth (email + password), Postgres with RLS, private `plant-photos` bucket
- Schema: [supabase/migrations](supabase/migrations)
- Edge Function [send-reminders](supabase/functions/send-reminders/index.ts) +
  pg_cron job `send-reminders` (hourly) for the daily push
- Edge Function [plant-ai](supabase/functions/plant-ai/index.ts): Claude photo checks

## Develop

    npm install
    npm run dev        # also reachable from a phone on the same Wi-Fi

`npm run build` type-checks and builds to `dist/`. Pushing to `main` deploys to
GitHub Pages via `.github/workflows/deploy.yml`.

## How scheduling works

- Next due = last watered + interval; never-watered plants are due right away.
- "Still wet" snoozes a plant 2 days without counting as watered.
- `water_plants(uuid[])` and `snooze_plant(uuid, int)` are SQL functions that also
  write `care_events`, so history stays consistent.

## Reminders (Web Push)

- Settings → Daily reminder subscribes this device (`push_subscriptions`) and stores
  time / weekdays-only / timezone (`reminder_settings`).
- pg_cron calls `send-reminders` every hour with `x-cron-secret`; each user gets one
  digest per local day, at or after their hour, only if plants are due.
- "Send test notification" calls the same function with the user's JWT.
- Secrets never leave Supabase: cron secret + VAPID keys are in Vault
  (VAPID pair generated by the function on first run, read via `push_config()`).
- iPhone: push only works from the home-screen app (iOS 16.4+).
- Deploy the function with `verify_jwt = false` (it checks the secret / JWT itself).

## Plant AI (Claude)

- New plant: picking a photo sends it to `plant-ai`, which asks Claude (Opus 5.5,
  structured output) for species, watering interval, light, a watering tip and a
  health check. The form is filled in; everything stays editable.
- Plant page → "Health check from a photo": same call with the plant's current
  schedule as context. Logs a note in the history and offers to adopt the suggested
  interval or the new photo.
- Needs the `ANTHROPIC_API_KEY` secret (Dashboard → Edge Functions → Secrets).
  Each call is logged in `ai_checks` (tokens included); 30 checks per user per day.
- Roughly 3 cents and 10 seconds per photo.
- Try the prompt locally: [claude.ts](supabase/functions/plant-ai/claude.ts) exports
  `checkPlant(apiKey, base64Jpeg, plant?)`.
- Deploy with `verify_jwt = false` (it checks the JWT itself).
